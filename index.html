FAQ

Built to be easy to explain.

Do guests need to install an app?

No. The feedback page opens from a QR code in the browser.

Can it match our restaurant brand?

Yes. Logo, primary color, restaurant name and Google review destination are configured per location.

What happens to the feedback data?

The frontend is designed to hand structured feedback and photos to your backend, database or notification workflow.

Can we add more locations later?

Yes. The intended production setup is location-based configuration, so additional restaurants can reuse the same system.
