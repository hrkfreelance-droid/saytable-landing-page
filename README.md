# SAYTABLE marketing site prototype

Responsive one-page landing page for SAYTABLE, a Cambodia-focused restaurant guest feedback and Google review support service.

## Working brand
- Name: SAYTABLE
- Positioning: Guest feedback for restaurants in Cambodia
- Tagline: Hear every table. Improve every visit.
- Primary color: #FF5B4D
- Ink: #17191D
- Background: #FAF9F6

## Current landing page
- English-first sales copy for restaurants, cafes and hospitality groups.
- Smartphone-led product visual based on the existing guest feedback flow.
- Sections for how it works, product value, real restaurant scenes, multilingual guests, setup, pricing, FAQ and pilot CTA.
- The live product concept currently presents Khmer, English and Simplified Chinese; the demo copy includes a Japanese-ready option for the planned four-language rollout.

## Notes
- Desktop / laptop / tablet are the primary layout targets.
- Mobile is fully responsive down to 390px-class screens.
- Pricing is a proposed launch price, not a finalized commercial term.
- SAYTABLE is a working name. Trademark and domain clearance have not been completed.
- The contact form is prototype-only and intentionally has no backend.
- The four-language landing-page switcher is not yet implemented; the current page remains English-only as requested for this prototype phase.
